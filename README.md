# Frontend Mentor - Product preview card component

A responsive product preview card built with semantic HTML and CSS.  
This project uses **BEM naming**, **Flexbox**, and an **accessible structure**.

## Preview

Desktop and mobile layouts are supported.

## Features

- Semantic HTML
- Accessible markup
- BEM CSS methodology
- Flexbox layout
- Responsive design
- Separate HTML and CSS files
- `box-sizing: border-box`
- Root font size set to `62.5%` for easier `rem` calculations

## Tech Stack

- HTML5
- CSS3
